# 人工收尾清单

脚本报告出现 `MANUAL` 时，按照下面顺序处理。

## 1. 真实手机

至少选择一台真实手机：

- 打开首页
- 从相册选择照片
- 输入 Top/Bottom Text
- 拖动或点击贴纸
- 切换 9:16
- 下载 PNG
- 检查键盘是否遮挡按钮
- 检查下载结果是否能在相册或文件中打开

## 2. 水印

打开：

```text
artifacts/时间/product/desktop-free-export.png
```

确认免费导出存在 MemePhoto AI 水印。

设置专用测试 License 后，再确认：

```text
desktop-creator-export.png
```

不存在水印。

## 3. Creem

日常验收只使用 Test Mode：

- 点击购买
- 完成测试付款
- 返回 `/success`
- 检查 License 邮件或测试结果
- 激活 License
- 再次导出

生产环境只在正式上线验收时人工完成一次，不要日常自动重复付款。

## 4. GSC

首次：

- 使用有权限访问该站点的 Google 账号登录。
- 添加 `memephotoai.com` 域名资源
- 完成 DNS TXT 验证

每次上线后：

- 查看 sitemap 状态
- 使用 URL 检查打开首页
- 必要时人工点击“请求编入索引”

## 5. GA4

- 登录 GA4
- 打开实时报告
- 访问网站
- 确认自己出现
- 确认 `page_view`
- 如已触发，确认 `day1_validation`
