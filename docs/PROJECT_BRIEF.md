# AI Meme Generator from Photo

## 1. 项目名称

AI Meme Generator from Photo

## 2. 项目目标

做一个简单、可信、可演示的网站，用于申请 Creem。

## 3. 第一版核心功能

- 用户上传一张照片
- 输入上方文字
- 输入下方文字
- 使用浏览器 Canvas 合成 meme 图片
- 支持下载 PNG
- 首页展示产品介绍
- 有 Pricing 页面
- 有 Privacy Policy、Terms of Service、Refund Policy、Contact 页面

## 4. 第一版不要做的事情

- 不接登录
- 不接数据库
- 不接 Stripe
- 不接真实 Creem 支付
- 不接 AI API
- 不做 GIF
- 不做 MP4
- 不做复杂后台
- 不做 SEO 页面矩阵

## 5. 技术方向

- Next.js
- Tailwind CSS
- 前端 Canvas
- Vercel 部署
- 图片只在浏览器本地处理，不上传服务器

## 6. 设计方向

使用几何卡片式 UI：

- 大圆角卡片
- 功能区块化
- 上传区域做成大卡片
- Pricing 做成价格卡片
- FAQ 做成折叠卡片
- 按钮使用胶囊按钮
- 页面风格年轻、轻松、专业、有产品感
